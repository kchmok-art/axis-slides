### Bagging

`ML` · Bootstrap Aggregating · 추가 2026-10-09

> **여러 모델을 각각 다른 데이터 샘플로 학습시킨 뒤 결과를 투표로 합치는 앙상블 방법**

**자세히**

Bagging은 전체 데이터에서 무작위로 샘플을 뽑아 여러 개의 모델을 독립적으로 학습시키고, 최종 예측은 다수결(분류) 또는 평균(회귀)으로 결정하는 방식이다. 한 모델이 틀려도 전체 결과에 큰 영향이 없어 과적합을 줄이고 안정성을 높인다. Random Forest가 Bagging의 대표 사례다.

**흐름**

- ① 전체 데이터에서 무작위 복원 샘플링(Bootstrap)
- ② 각 샘플로 독립적인 모델 학습
- ③ N개 모델 완성
- ④ 예측: N개 모델 각각 예측 → 다수결(분류) 또는 평균(회귀)

**헷갈리는 점**

- **흔한 오해** Bagging과 Boosting 혼동
- **차이** Bagging = 독립적 병렬 학습(과적합 방지) / Boosting = 순차 학습(이전 모델 오류에 집중)
- **기억법** Bagging = 각자 따로 공부 후 다수결 / Boosting = 틀린 문제 집중 복습

**예시**

- 100명의 의사에게 같은 X-ray를 보여주고 다수결로 진단 → Bagging과 동일
- 데이터 1000개 → 800개씩 랜덤 추출 → 모델 10개 학습 → 다수결
- 한 모델이 과적합돼도 나머지 9개가 바로잡음
- Bootstrap(무작위 샘플링) + Aggregating(결과 합산) = Bagging

**카톡으로 이해하기**

> **💬 A** Bagging이 뭔지 알아?
>
> **🙋 B** 가방 드는 거?
>
> **💬 A** ㅋㅋ 머신러닝에서 Bagging은 여러 모델을 독립적으로 병렬 학습해서 다수결 내리는 기법이야  
> Bootstrap Aggregating 줄임말이야
>
> **🙋 B** 왜 하나만 안 쓰는 거야?
>
> **💬 A** 모델 하나는 틀릴 수 있어. 여러 모델이 각자 독립적으로 예측하면  
> 한 모델이 틀려도 다수가 맞으면 결과가 맞아
>
> **🙋 B** 아 위원회 투표 같은 거네
>
> **💬 A** 맞아! Boosting이랑 헷갈릴 수 있는데  
> Bagging = 각자 따로 공부 후 다수결 / Boosting = 틀린 문제 집중 복습 순차 학습이야  
> Random Forest가 Bagging 대표 사례야

### CNN (Convolutional Neural Network)

`ML` · Convolutional Neural Network · 추가 2026-10-09

> **이미지에서 특징을 자동으로 추출하는 딥러닝 구조 — 시각 인식의 핵심**

**자세히**

CNN은 이미지를 작은 필터(커널)로 훑으며 선·모서리·텍스처·형태 등 특징을 단계적으로 추출하는 신경망이다. 사람이 특징을 직접 정의하지 않아도 학습을 통해 스스로 중요한 패턴을 찾아낸다. 이미지 분류·얼굴 인식·자율주행 등에 핵심적으로 사용된다.

**흐름**

- ① 이미지 픽셀 입력
- ② 컨볼루션 필터로 특징 추출(선·모서리)
- ③ 풀링(Pooling)으로 크기 축소
- ④ 여러 번 반복 → 추상적 특징 추출
- ⑤ Flatten → FC 레이어 → 분류

**헷갈리는 점**

- **흔한 오해** CNN을 이미지 전용이라고 오해
- **차이** CNN은 이미지가 주력이지만 텍스트·오디오·시계열에도 사용 가능
- **기억법** CNN = 이미지의 왕 (다른 곳도 쓰이지만 이미지가 본업)

**예시**

- 얼굴 인식 — CNN이 픽셀 → 선 → 눈·코·입 → 얼굴 순으로 특징 추출
- 자율주행 카메라 — 도로·사람·신호등 실시간 인식
- 의료 이미지 — X-ray에서 폐암 의심 부위 자동 감지
- 인스타그램 필터 — CNN이 얼굴 위치를 잡아 효과 적용

**카톡으로 이해하기**

> **💬 A** CNN이 이미지 인식할 때 쓰는 거잖아. 어떻게 동작해?
>
> **🙋 B** 그냥 이미지 입력하면 분류해주는 거 아니야?
>
> **💬 A** 원리가 있어. 이미지의 패턴(에지, 곡선, 질감 등)을 계층적으로 추출해  
> 가장자리 찾기 → 모양 찾기 → 얼굴 특징 찾기 이런 식으로
>
> **🙋 B** 아 단계적으로 점점 복잡한 패턴 인식하는 거구나
>
> **💬 A** 맞아! 합성곱(Convolution) 연산으로 이미지 특징 뽑아내서  
> Transformer 나오기 전까지 이미지 처리의 표준이었어
>
> **🙋 B** 지금도 써?
>
> **💬 A** 응! 이미지 분류, 객체 탐지, 의료 영상 분석에 많이 써  
> CNN = 이미지 전용 딥러닝 구조로 기억해

### Cut-off (컷오프)

`ML` · Cut-off · 추가 2026-10-09

> **학습 데이터의 시간적 기준점 — 이 날짜 이후 정보는 모델이 모른다**

**자세히**

Cut-off는 AI 모델의 학습 데이터가 어디까지 포함됐는지의 시간 기준이다. Cut-off 이후에 일어난 사건은 모델이 학습하지 않았으므로 알 수 없다. LLM에서 '지식 마감일(Knowledge Cutoff)'이라고도 한다.

**흐름**

- ① 데이터 수집 기간 설정
- ② Cut-off 날짜 이후 데이터는 포함 안 함
- ③ Cut-off 이전 데이터만으로 모델 학습
- ④ 배포 후 시간이 지나면 새 데이터 반영 안 됨

**헷갈리는 점**

- **흔한 오해** Cut-off를 Threshold(임계값)와 혼동하기 쉬움
- **차이** Cut-off는 시간 기준(언제까지 아는가), Threshold는 확률 기준(얼마 이상이면 참인가)
- **기억법** Cut-off = 지식의 만료일 / Threshold = 판단의 기준선

**예시**

- ChatGPT-4의 Cut-off = 2023년 4월 → 그 이후 뉴스·사건은 모름
- '최근 AI 근황 알려줘' → Cut-off 이후면 모르거나 틀린 정보 줄 수 있음
- RAG로 최신 문서를 넣어주면 Cut-off 한계를 보완 가능
- 모델 학습 비용이 크기 때문에 자주 업데이트하기 어려워 Cut-off 존재

**카톡으로 이해하기**

> **💬 A** Cut-off가 뭔지 알아?
>
> **🙋 B** 뭔가 자르는 거?
>
> **💬 A** LLM 맥락에서 Cut-off는 모델이 학습한 데이터의 마지막 날짜야  
> 그 날짜 이후 일은 모르는 거지
>
> **🙋 B** 아 그래서 GPT한테 최신 뉴스 물어보면 모른다는 거구나
>
> **💬 A** 맞아! 예를 들어 학습 Cut-off가 2024년 9월이면  
> 그 이후에 일어난 일은 모델이 몰라
>
> **🙋 B** Threshold(임계값)랑 헷갈리는 사람 있을 것 같아
>
> **💬 A** 달라! Cut-off = 시간 기준 (언제까지 아는가)  
> Threshold = 확률 기준 (얼마 이상이면 참인가)  
> Cut-off = 지식의 만료일이야

### DataOps (데이터옵스)

`ML` · Data Operations · 추가 2026-10-31

> **식재료 공급망 — 신선하고 정확한 재료가 제때 들어오게**

**정의** 데이터를 모으고, 정리하고, 검사하고, 필요한 곳에 전달하는 과정(데이터 파이프라인)을 자동화하고 품질을 관리하는 방식.

**자세히**

비유: 셰프가 아무리 뛰어나도 상한 재료나 틀린 재료가 오면 요리를 망친다. 산지에서 주방까지 재료가 신선하게, 정확한 양으로, 제때 오도록 공급망을 관리한다.  
실제: 수집 → 정제 → 검사(빠진 값·이상한 값·중복) → 저장 → 대시보드·모델로 전달을 자동 파이프라인으로 돌리고, 단계마다 품질 테스트를 넣는다. 도구: Airflow, dbt, Great Expectations 등.  
AI와의 관계: MLOps·LLMOps의 재료 공급 담당. 쓰레기가 들어가면 쓰레기가 나온다(Garbage In, Garbage Out).

**흐름**

- ① 수집
- ② 정제 — 형식 맞추기·중복 제거
- ③ 품질 검사 — 빈값·이상값
- ④ 저장
- ⑤ 전달 — 대시보드·모델
- ⑥ 감시 — 늦거나 틀리면 알림

**헷갈리는 점**

- **흔한 오해** DataOps vs MLOps
- **차이** DataOps = 재료(데이터)를 제대로 공급 / MLOps = 그 재료로 요리사(모델)를 키우고 운영
- **기억법** 공급망(DataOps) → 셰프 훈련(MLOps)

**예시**

- 매일 새벽 판매 데이터를 모아 정리 → 아침 9시 대시보드 자동 갱신
- 새로 들어온 데이터에 빈칸이 갑자기 늘면 파이프라인 멈추고 알림
- RAG용 문서를 매주 최신본으로 갈아 끼우기

**카톡으로 이해하기**

> **💬 A** 데이터옵스는 데이터 분석이야?
>
> **🙋 B** 엑셀로 분석하는 거 아니야?
>
> **💬 A** 분석 전 단계야. 데이터가 정확하게, 제때, 자동으로 들어오게 하는 일
>
> **🙋 B** 그게 왜 중요해?
>
> **💬 A** 재료가 상하면 셰프가 아무리 잘해도 요리를 망치잖아  
> AI도 데이터가 틀리면 틀린 답을 내

### Decision Tree (결정 트리)

`ML` · Decision Tree · 추가 2026-10-09 · 보강 2026-10-25

> **스무고개처럼 예/아니오 질문을 반복해 결론을 내리는 트리 구조 분류 알고리즘**

**자세히**

Decision Tree는 데이터를 분기 조건(예/아니오)으로 나눠가며 최종 결론에 도달하는 알고리즘이다. 구조가 직관적이라 사람이 이해하기 쉽고, 결과를 시각화할 수 있다. 단점은 데이터에 과적합되기 쉽다는 것 — 이를 해결하기 위해 Random Forest가 등장했다.  
\[lecture\_017 보강\] 분할 기준은 지니 불순도(또는 엔트로피) 감소다. 축과 평행한 계단식 결정 경계를 만든다. lecture\_017 데모에서 트리 1개는 두 반달 데이터 학습 정확도 98.1%였지만 경계가 거칠었다(학습 데이터 기준이라 일반화는 별도 확인 필요).

**흐름**

- ① 루트 노드: 가장 중요한 특징으로 분기
- ② 각 분기: 예/아니오 조건
- ③ 반복 분기 → 잎 노드(최종 결론) 도달
- ④ 예측: 새 데이터가 어느 잎에 속하는지 확인

**헷갈리는 점**

- **흔한 오해** Decision Tree를 Random Forest와 혼동
- **차이** Decision Tree = 나무 1그루(과적합 쉬움) / Random Forest = 나무 수백 그루 다수결(안정적)
- **기억법** Decision Tree = 스무고개 1명이 하기 / Random Forest = 스무고개 100명이 동시에

**예시**

- 대출 승인 여부: 소득 > 300만원? → 신용점수 > 700? → 승인/거절
- 스팸 분류: '무료'단어 포함? → 발신자 모름? → 스팸/정상
- 스무고개와 동일한 원리 — 질문을 좁혀가며 정답 도달
- 장점: 결과 해석 가능 / 단점: 과적합 쉬움 → Bagging·Random Forest로 해결

**카톡으로 이해하기**

> **💬 A** Decision Tree가 뭔지 알아?
>
> **🙋 B** 결정 나무? 트리 구조야?
>
> **💬 A** 맞아! 스무고개처럼 예/아니오 질문 반복해서 결론 내리는 모델이야  
> '나이 > 30?' → '예' → '수입 > 5000?' → 이런 식으로 분기해서 결론에 도달해
>
> **🙋 B** 딥러닝이랑 뭐가 달라?
>
> **💬 A** 딥러닝처럼 복잡한 연산이 없어서 결과를 사람이 이해하기 쉬워  
> 어떤 조건으로 판단했는지 직접 볼 수 있는 게 장점이야
>
> **🙋 B** 근데 Random Forest랑은 다른 거야?
>
> **💬 A** Decision Tree는 나무 1그루야. 과적합이 쉽게 일어나는 단점이 있어  
> Random Forest는 나무 수백 그루 만들어서 다수결 내리는 거야  
> Decision Tree = 스무고개 1명이 하기야

### GAN (Generative Adversarial Network)

`ML` · Generative Adversarial Network · 추가 2026-10-09

> **생성자와 판별자가 서로 경쟁하며 진짜 같은 가짜 데이터를 만들어내는 딥러닝 구조**

**자세히**

GAN은 두 신경망이 대결하는 구조다. 생성자(Generator)는 가짜 이미지를 만들고, 판별자(Discriminator)는 진짜/가짜를 구분한다. 생성자는 판별자를 속이려 하고, 판별자는 더 잘 구분하려 하면서 서로 발전한다. 딥페이크·이미지 생성의 핵심 기술이었다.

**흐름**

- ① 생성자: 랜덤 노이즈 → 가짜 데이터 생성
- ② 판별자: 진짜vs가짜 분류
- ③ 판별자 학습(진짜=1, 가짜=0)
- ④ 생성자 학습(판별자를 속이도록)
- ⑤ 반복 → 생성자가 점점 정교해짐

**헷갈리는 점**

- **흔한 오해** GAN이 현재도 이미지 생성 주류라고 오해
- **차이** GAN은 2020년대 초까지 주류였지만 현재는 Diffusion Model(DALL-E, Stable Diffusion)이 대세
- **기억법** GAN = 위조지폐범 vs 경찰 대결 / Diffusion = 노이즈에서 점차 선명하게

**예시**

- 딥페이크 — GAN이 실존하지 않는 사람 얼굴을 생성
- ThisPersonDoesNotExist.com — GAN이 만든 가짜 인물 사진
- 생성자=위조지폐범 / 판별자=경찰 — 서로 실력이 올라가며 완벽한 위조 달성
- 지금은 Diffusion Model(Stable Diffusion, DALL-E)이 이미지 생성 주류로 대체

**카톡으로 이해하기**

> **💬 A** GAN이 가짜 이미지 만드는 거 맞아?
>
> **🙋 B** 딥페이크 그거야?
>
> **💬 A** GAN 기반 기술이 맞아. Generative Adversarial Network  
> 생성자(Generator)와 판별자(Discriminator) 두 모델이 서로 경쟁하며 학습해
>
> **🙋 B** 경쟁한다는 게 어떻게?
>
> **💬 A** 생성자는 진짜같은 가짜를 만들려고 하고  
> 판별자는 진짜와 가짜를 구별하려고 해  
> 이 대결이 반복되면서 생성자가 점점 정교해지는 거야
>
> **🙋 B** 아 위조지폐범 vs 경찰 대결 같은 거네
>
> **💬 A** 딱 그 비유야! 근데 지금은 Diffusion 모델(DALL-E, Stable Diffusion)이 더 쓰여  
> GAN의 학습이 불안정한 단점을 개선한 거야

### LSTM (Long Short-Term Memory)

`ML` · Long Short-Term Memory · 추가 2026-10-09

> **RNN의 장기 기억 문제를 해결한 개선된 순환 신경망 — 중요한 정보를 오래 기억**

**자세히**

LSTM은 RNN이 긴 문장에서 앞부분을 잊는 문제를 해결하기 위해 '게이트(gate)' 구조를 추가한 신경망이다. 기억할 것(input gate)·잊을 것(forget gate)·출력할 것(output gate)을 스스로 학습한다. Transformer 등장 전까지 번역·음성 인식의 핵심 기술이었다.

**흐름**

- ① 입력 + 이전 셀 상태(장기 기억) + 이전 은닉 상태
- ② Forget Gate: 버릴 정보 결정
- ③ Input Gate: 저장할 정보 결정
- ④ 셀 상태 업데이트
- ⑤ Output Gate: 출력 결정

**헷갈리는 점**

- **흔한 오해** LSTM을 RNN과 완전히 다른 것으로 오해
- **차이** LSTM ⊂ RNN — LSTM은 게이트 구조를 추가한 개선된 RNN
- **기억법** RNN = 단기 기억만 있는 사람 / LSTM = 장기·단기 기억 모두 있는 사람

**예시**

- '나는 한국에서 태어나 미국에서 살았고 지금은 일본에 있다. 나는 (  )어를 쓴다'
- → LSTM은 '일본'을 기억해 '일본어'를 예측 (RNN은 잊어버림)
- 구글 번역 초기 버전 — LSTM 기반
- 음성 인식 — 긴 문장에서 앞 음절 맥락 유지에 활용
- 지금은 대부분 Transformer로 대체됐지만 시계열·임베디드에서 여전히 사용

**카톡으로 이해하기**

> **💬 A** LSTM이 뭔데?
>
> **🙋 B** RNN 개선판?
>
> **💬 A** 맞아! Long Short-Term Memory. RNN의 장기 의존성 문제 해결한 버전이야  
> 긴 텍스트에서 앞 내용을 오래 기억할 수 있는 구조
>
> **🙋 B** RNN이 기억 못 하는 문제가 뭐야?
>
> **💬 A** 예를 들어 '오늘 아침에 일어나서 밥 먹고 학교 가서 공부하다가 집에 왔는데 피곤하다'  
> RNN은 앞의 '아침'을 기억 못 할 수 있어  
> LSTM은 셀 상태(Cell State)라는 기억 통로로 중요한 정보를 오래 유지해
>
> **🙋 B** 근데 지금은 Transformer가 더 좋은 거야?
>
> **💬 A** 응! Transformer가 LSTM보다 병렬 처리 되고 성능도 좋아서  
> 현재 NLP의 표준은 Transformer야

### Random Forest

`ML` · Random Forest · 추가 2026-10-09 · 보강 2026-10-25

> **수많은 Decision Tree를 Bagging으로 학습시켜 다수결로 예측하는 강력한 앙상블 알고리즘**

**자세히**

Random Forest는 Decision Tree를 수백~수천 개 만들되, 각 트리가 무작위로 선택된 데이터와 특징(feature)으로 학습하게 해 서로 다른 트리들이 협력해 예측한다. 단일 Decision Tree보다 훨씬 정확하고 과적합에 강하다. 표 형태 데이터에서 지금도 강력한 성능을 보인다.  
\[lecture\_017 보강\] 부트스트랩 표본 + 무작위 특성 선택으로 트리를 여러 개 만들어 다수결한다. 주요 하이퍼파라미터: n\_estimators·max\_depth·min\_samples\_split·min\_samples\_leaf·max\_features. 트리 수를 늘리면 예측이 안정되다가 어느 순간 개선이 멈추고 계산 비용만 는다. 변수 중요도(지니 감소 비중)는 분할에 기여한 상대적 단서일 뿐 인과가 아니며, 상관된 변수끼리 중요도를 나눠 갖거나 값의 종류가 많은 변수가 부풀려질 수 있다(→ permutation importance·SHAP으로 교차 확인).

**흐름**

- ① 데이터 Bootstrap 샘플링
- ② 각 트리: 무작위 특징 서브셋으로 학습
- ③ N개 Decision Tree 완성
- ④ 예측: 전체 트리 다수결

**헷갈리는 점**

- **흔한 오해** Random Forest가 딥러닝보다 항상 나쁘다고 오해
- **차이** Random Forest = 표 형태 데이터·소규모·해석 필요할 때 강력 / 딥러닝 = 이미지·텍스트·대규모에 강력
- **기억법** Random Forest = 숲(나무 많을수록 안정) / 딥러닝 = 거대한 공장(대규모 처리)

**예시**

- 나무 1개(Decision Tree) = 한 명의 의사 / 숲(Forest) = 수백 명 의사의 다수결
- 신용 평가·의료 진단·부동산 가격 예측에서 여전히 널리 사용
- 각 트리는 서로 다른 특징·데이터 조합으로 학습 → 다양한 시각 확보
- 딥러닝보다 데이터 적을 때, 해석이 필요할 때 Random Forest 선호

**카톡으로 이해하기**

> **💬 A** Random Forest가 왜 이름이 숲이야?
>
> **🙋 B** 나무가 많아서?
>
> **💬 A** 맞아! Decision Tree(나무)를 수백 개 만들어서 다수결로 예측하는 거야  
> 각 나무가 무작위 특징 서브셋으로 학습해서 다양성 확보
>
> **🙋 B** 그냥 Decision Tree 하나 쓰면 안 돼?
>
> **💬 A** Decision Tree 하나는 과적합이 쉽게 일어나서 새 데이터에 약해  
> Random Forest는 여러 나무가 투표하니까 훨씬 안정적이야
>
> **🙋 B** 딥러닝보다 나쁜 거야?
>
> **💬 A** 무조건 그런 건 아니야. 표 형태 데이터나 소규모 데이터에선 Random Forest가 강해  
> 이미지·텍스트·대규모 데이터에는 딥러닝이 강하고  
> Random Forest = 숲(나무 많을수록 안정)으로 기억해

### RNN (Recurrent Neural Network)

`ML` · Recurrent Neural Network · 추가 2026-10-09

> **순서가 있는 데이터(텍스트·시계열)를 앞에서부터 순서대로 처리하는 신경망**

**자세히**

RNN은 이전 단계의 출력을 다음 단계의 입력으로 넘기며 순서 정보를 기억하는 신경망이다. 문장을 단어 순서대로 처리하거나 시계열 데이터를 다룰 때 강점이 있다. 하지만 긴 문장에서 앞부분을 잊어버리는 장기 의존성 문제가 있어 LSTM, Transformer로 발전했다.

**흐름**

- ① 첫 번째 토큰 입력 + 초기 은닉 상태
- ② 출력 + 새 은닉 상태 계산
- ③ 은닉 상태를 다음 단계로 전달
- ④ 다음 토큰 입력 + 이전 은닉 상태
- ⑤ 반복 → 마지막 토큰까지

**헷갈리는 점**

- **흔한 오해** RNN이 Transformer보다 항상 나쁘다고 오해
- **차이** RNN = 순서 데이터·경량 모델에 여전히 유용 / Transformer = 긴 문장·대규모에 강력
- **기억법** RNN = 1인 기억력 좋은 직원 / Transformer = 팀 전체가 동시에 보는 구조

**예시**

- '나는 오늘 학교에 갔다' → 단어를 순서대로 처리하며 문맥 기억
- 주가 예측 — 어제·오늘·내일 순서가 있는 시계열 데이터 처리
- 번역 — 앞 단어를 기억하며 다음 단어 예측
- RNN 한계: '나는... (100단어)... 갔다' → 앞부분 '나는' 잊어버림 → LSTM으로 해결

**카톡으로 이해하기**

> **💬 A** RNN이 텍스트 처리할 때 쓰인다던데 지금도 써?
>
> **🙋 B** 지금은 Transformer 쓰는 거 아니야?
>
> **💬 A** 맞아. RNN은 Transformer 나오기 전에 많이 썼어  
> 순서가 있는 데이터(텍스트, 시계열)를 순서대로 처리하는 구조야
>
> **🙋 B** 어떻게 순서 처리해?
>
> **💬 A** 앞 단어 처리한 결과를 다음 단어 처리할 때 같이 써  
> '오늘 날씨가 맑다'를 순서대로 '오늘' → '날씨가' → '맑다' 처리하는 거야
>
> **🙋 B** 그럼 뭐가 문제였어?
>
> **💬 A** 순서대로 처리해서 병렬화가 안 돼. 느려  
> 그리고 긴 문장에서 앞 내용을 점점 잊어버리는 문제도 있어  
> 그걸 보완한 게 LSTM이고, 결국 Transformer로 대체됐어

### ROC-AUC

`ML` · Receiver Operating Characteristic · Area Under the Curve · 추가 2026-10-25

> **0.5 = 동전 던지기, 1 = 완벽 — 임계값과 무관한 순위 능력 점수**

**정의** 임계값을 바꿔 가며 재현율(TPR)과 거짓양성률(FPR)을 그린 곡선(ROC)의 아래 넓이(AUC) — 모델이 양성을 음성보다 높게 점수 매기는 능력

**자세히**

AUC는 '양성 하나와 음성 하나를 무작위로 뽑았을 때 모델이 양성에 더 높은 점수를 줄 확률'로 해석할 수 있다. 확률이나 점수가 필요하다(SVM은 결정함수 점수로 계산 가능). 모델 비교는 같은 검증 분할(같은 교차검증 폴드)에서 한다. 양성이 아주 적으면 ROC-AUC가 낙관적으로 보일 수 있어 PR-AUC(정밀도-재현율 곡선)도 함께 본다. AUC가 높아도 실제 운영 임계값은 비용을 보고 따로 정해야 한다. \[lecture\_017\]

**흐름**

- ① 검증 데이터에 점수(확률) 예측
- ② 임계값을 높은 값→낮은 값으로 바꾸며 TPR·FPR 계산
- ③ 점들을 이어 ROC 곡선
- ④ 곡선 아래 넓이 = AUC로 모델 비교

**헷갈리는 점**

- **흔한 오해** AUC가 높으면 바로 현장에 써도 된다고 생각
- **차이** AUC = 줄 세우는 능력(임계값 무관) / 실제 판정은 임계값에 따라 정밀도·재현율이 달라짐
- **기억법** AUC는 줄 세우기 실력, 임계값은 어디서 끊을지

**예시**

- AUC 0.92 → 양성·음성 한 쌍을 뽑으면 92%는 양성 점수가 더 높음
- 같은 5-fold에서 SVM AUC 0.90 vs RF AUC 0.93 비교

**카톡으로 이해하기**

> **💬 A** ROC-AUC 0.5면 어떤 모델이야?
>
> **🙋 B** 반은 맞히는 거?
>
> **💬 A** 동전 던지기 수준이란 뜻이야. 1이면 완벽
>
> **🙋 B** 정확도랑 뭐가 달라?
>
> **💬 A** 정확도는 기준선 하나에서 재지만, AUC는 기준선을 다 바꿔 보며 재
>
> **🙋 B** 그럼 AUC만 높으면 끝?
>
> **💬 A** 아니. 실제로 쓸 땐 어디서 끊을지 임계값을 비용 보고 따로 정해야 해

### SVM (Support Vector Machine)

`ML` · Support Vector Machine · 추가 2026-10-09 · 보강 2026-10-25

> **데이터를 가장 잘 나누는 경계선(결정 경계)을 찾아 분류하는 머신러닝 알고리즘**

**자세히**

SVM은 두 클래스의 데이터를 가장 넓은 여백(margin)으로 구분하는 경계선을 찾는 알고리즘이다. 딥러닝 이전에 분류 문제에서 강력한 성능을 보였다. 데이터가 적을 때도 잘 작동하는 장점이 있다.  
\[lecture\_017 보강\] SVM은 확률분포를 가정하지 않고 결정함수 f(x)=w·x+b의 부호로 분류하는 기하학적 모델이다(확률모형 아님 — 확률이 필요하면 Platt scaling 등으로 보정). 하이퍼파라미터: C가 클수록 오분류를 덜 허용해 학습 데이터에 딱 맞는 좁은 마진(과적합 위험), gamma가 클수록 RBF 커널에서 점 하나의 영향 범위가 좁아져 경계가 구불구불해진다. 해석은 선형 SVM이 계수로 어느 정도 가능하고, RBF 커널 SVM은 경계를 바로 읽기 어렵다(기존 '해석이 필요할 때 강력'은 선형 SVM에 한정).

**흐름**

- ① 데이터 포인트를 고차원 공간에 매핑
- ② 두 클래스를 가장 넓은 마진으로 나누는 경계선 탐색
- ③ 서포트 벡터(경계에 가장 가까운 점) 확인
- ④ 분류 경계선 확정 → 예측

**헷갈리는 점**

- **흔한 오해** SVM을 딥러닝과 비교해 구식이라고 오해
- **차이** SVM = 데이터가 적고 차원이 높을 때도 강력(해석은 선형 SVM에서만 비교적 쉬움) / 딥러닝 = 데이터가 많을 때 강력
- **기억법** SVM = 정밀 수술 도구(소규모·정확) / 딥러닝 = 대형 병원(대규모·강력)

**예시**

- 고양이 vs 개 사진 → SVM이 두 그룹을 가장 잘 나누는 선을 찾음
- 스팸 메일 분류 — 딥러닝 이전 시대의 대표 분류 알고리즘
- 마진(margin) = 두 클래스 사이의 여백 — 이걸 최대화하는 게 SVM의 목표
- 서포트 벡터 = 경계선에 가장 가까운 데이터 포인트들

**카톡으로 이해하기**

> **💬 A** SVM이 뭔지 알아?
>
> **🙋 B** 뭔가 머신러닝 알고리즘?
>
> **💬 A** 맞아! Support Vector Machine. 데이터를 두 그룹으로 나누는 경계선 찾는 알고리즘이야  
> 두 그룹 사이의 간격(마진)이 가장 큰 경계선을 찾는 게 핵심이야
>
> **🙋 B** 딥러닝이랑은 다른 거야?
>
> **💬 A** 딥러닝 나오기 전에 많이 쓰던 전통 머신러닝 알고리즘이야  
> 딥러닝보다 적은 데이터로도 잘 작동하고 결과 해석도 쉬워
>
> **🙋 B** 그럼 지금도 써?
>
> **💬 A** 데이터가 작거나, 이진 분류, 의료 데이터 같이 해석이 중요한 경우엔 여전히 써  
> 모든 문제에 딥러닝이 최선은 아니야

### Threshold (임계값)

`ML` · Threshold · 추가 2026-10-09 · 보강 2026-10-25

> **모델의 예측 확률을 어떤 기준으로 결론(참/거짓)으로 바꿀지 결정하는 경계값**

**자세히**

Threshold는 모델이 출력한 확률값을 '예/아니오'로 변환하는 기준선이다. 예를 들어 스팸 확률이 0.7이 넘으면 스팸으로 분류하는 것처럼, 어디서 선을 그을지 정하는 값이다. 높이면 정밀도 상승·재현율 하락, 낮추면 그 반대가 된다.  
\[lecture\_017 보강\] 임계값과 무관하게 모델의 순위 능력을 보려면 ROC-AUC, 특정 임계값에서 어떤 실수를 하는지는 혼동행렬로 본다. 어느 임계값을 쓸지는 거짓양성·거짓음성 비용으로 정한다.

**흐름**

- ① 모델이 각 클래스 확률 출력(0~1)
- ② Threshold 값 설정(보통 0.5)
- ③ 확률 ≥ Threshold → 양성 분류
- ④ 확률 &lt; Threshold → 음성 분류
- ⑤ Threshold 조정으로 정밀도·재현율 트레이드오프

**헷갈리는 점**

- **흔한 오해** Threshold를 Cut-off와 혼동하기 쉬움. 또한 높이면 무조건 좋다고 오해하기 쉬움
- **차이** Cut-off는 시간 기준, Threshold는 확률 기준
- **tradeoff** {'낮게(0.3)': '놓치는 스팸 줄어듦 → 정상메일 오분류 늘어남 (재현율↑ 정밀도↓)', '높게(0.9)': '정상메일 오분류 줄어듦 → 스팸 놓칠 수 있음 (정밀도↑ 재현율↓)'}
- **사용예** 암 진단=낮게(놓치면 안 됨) / 보안 차단=높게(오탐 줄여야 함)
- **기억법** Threshold = 어디서 선 그을 것인가

**예시**

- 스팸 필터: 확률 > 0.5 → 스팸 (threshold=0.5)
- 암 진단: 확률 > 0.3 → 정밀 검사 권고 (놓치면 안 되니 낮게 설정)
- 보안 시스템: 확률 > 0.9 → 차단 (오탐 줄이려고 높게 설정)
- threshold 0.5 → 0.7로 올리면: 스팸 판단 더 엄격 → 정상메일 스팸 오분류 줄어듦

**카톡으로 이해하기**

> **💬 A** Threshold가 뭐야? 임계값?
>
> **🙋 B** 기준선 같은 거?
>
> **💬 A** 맞아! 분류 모델이 예측한 확률이 얼마 이상이면 '양성'으로 볼지 결정하는 기준이야  
> 보통 0.5 쓰는데, 상황에 따라 바꿔
>
> **🙋 B** 왜 바꿔?
>
> **💬 A** 암 진단 모델이면 놓치면 큰일이니까 기준을 낮춰 → 재현율 높임  
> 스팸 필터는 정상 메일 오분류가 더 나쁘니까 기준 높여 → 정밀도 높임
>
> **🙋 B** 아 높이고 낮추면 트레이드오프가 있구나
>
> **💬 A** 맞아! 낮추면 더 많이 양성으로 분류, 높이면 더 엄격하게 양성 분류  
> Threshold = 어디서 선 그을 것인가야

**정의** 손실 함수의 기울기 반대 방향으로 파라미터를 조금씩 옮겨 손실이 가장 작은 지점을 찾아가는 최적화 방법

**자세히**

θ ← θ − η·∇손실. η(학습률)가 너무 크면 손실이 튀거나 발산하고, 너무 작으면 느리다. 전체 데이터로 한 번에 하면 배치 경사하강, 한 샘플씩이면 SGD(확률적 경사하강), 묶음씩이면 미니배치. Adam 같은 옵티마이저는 이를 개선한 것이다. 신경망에서는 기울기를 역전파로 계산한다. 로지스틱 회귀도 경사하강으로 적합할 수 있다. \[lecture\_017\]

**흐름**

- ① 현재 파라미터로 손실 계산
- ② 손실의 기울기 계산(신경망은 역전파)
- ③ 기울기 반대 방향으로 학습률만큼 이동
- ④ 손실이 더 줄지 않을 때까지 반복

**헷갈리는 점**

- **흔한 오해** 경사하강법과 역전파를 같은 것으로 봄
- **차이** 역전파 = 기울기 계산 방법 / 경사하강법 = 그 기울기로 파라미터를 옮기는 방법
- **기억법** 역전파는 경사 측정기, 경사하강은 걸음

**예시**

- 학습률 0.01로 1,000번 반복해 손실이 0.69 → 0.15로 감소
- lecture\_017 데모: 로지스틱 회귀(420에포크)와 작은 신경망(520에포크)을 브라우저에서 경사하강으로 학습

**카톡으로 이해하기**

> **💬 A** 경사하강법은 안개 낀 산에서 내려가는 방법이야
>
> **🙋 B** 앞이 안 보이는데 어떻게 내려가?
>
> **💬 A** 발밑 경사만 보고 낮은 쪽으로 한 걸음씩
>
> **🙋 B** 한 걸음 크기는?
>
> **💬 A** 그게 학습률이야. 너무 크면 골짜기를 넘어가고, 너무 작으면 하루 종일 걸려
>
> **🙋 B** 역전파랑 같은 거야?
>
> **💬 A** 역전파가 경사를 재고, 경사하강법이 걸어. 둘이 짝이야

### 과적합과 일반화 (Overfitting·Generalization)

`ML` · Overfitting · Generalization · 추가 2026-10-25

> **기출만 외운 학생(과적합) vs 처음 보는 문제도 푸는 학생(일반화)**

**정의** 일반화는 학습에 없던 새 데이터에서도 잘 작동하는 성질이고, 과적합은 학습 데이터에만 지나치게 맞춰져 일반화에 실패한 상태

**자세히**

학습 성능은 높은데 검증·테스트 성능이 낮으면 과적합, 둘 다 낮으면 과소적합이다. 모델이 복잡할수록(깊은 트리, 큰 C·gamma, 큰 신경망) 과적합 위험이 커진다. 교차검증으로 확인하고, 규제(L1·L2, Dropout, Early Stopping)·데이터 추가·모델 단순화로 줄인다. 보편 근사 정리는 신경망이 어떤 경계든 '표현할 수 있다'는 뜻이지 유한한 데이터에서 일반화된다는 보장이 아니다. \[lecture\_017\]

**흐름**

- ① 학습·검증 성능을 함께 기록
- ② 학습↑ 검증↓ 이면 과적합 신호
- ③ 규제·데이터 추가·모델 단순화
- ④ 교차검증으로 다시 확인

**헷갈리는 점**

- **흔한 오해** 학습 정확도가 높으면 좋은 모델이라고 생각
- **차이** 학습 정확도 = 외운 정도 / 검증·테스트 정확도 = 실력(일반화)
- **기억법** 기출 100점보다 모의고사 점수

**예시**

- 결정 트리를 끝까지 키우면 학습 정확도 100%, 새 데이터 정확도는 뚝 떨어짐
- 학습곡선: 학습 손실은 계속 주는데 검증 손실이 다시 오르면 과적합 시작 → Early Stopping

**카톡으로 이해하기**

> **💬 A** 과적합이 뭔지 알아?
>
> **🙋 B** 너무 잘 맞는 거? 좋은 거 아냐?
>
> **💬 A** 학습 데이터만 너무 잘 맞는 거야. 기출만 외운 학생 같은 거
>
> **🙋 B** 아 새 문제는 못 풀겠네
>
> **💬 A** 맞아. 새 데이터도 잘 맞히는 게 일반화야
>
> **🙋 B** 어떻게 알아채?
>
> **💬 A** 학습 점수는 높은데 검증 점수가 낮으면 과적합 신호야
>
> **🙋 B** 막는 법은?
>
> **💬 A** 모델을 단순하게 하거나, 데이터를 늘리거나, 규제를 걸어

### 교차 엔트로피 (Cross-Entropy)

`ML` · Cross-Entropy Loss · 추가 2026-10-25

> **분류 모델의 대표 손실 함수 = 음의 로그우도**

**정의** 모델이 낸 확률이 정답과 얼마나 어긋나는지 재는 손실 — 확신하고 틀릴수록 벌점이 크게 커진다

**자세히**

이진 분류: loss = −\[y log p + (1−y) log(1−p)\]. 정답이 1인데 p=0.99면 손실 약 0.01, p=0.01이면 약 4.6으로 급격히 커진다. 베르누이 모형의 음의 로그우도와 같아서, 교차 엔트로피를 최소화하는 것 = 우도를 최대화(MLE)하는 것이다. 로지스틱 회귀와 시그모이드 출력 신경망이 같은 손실을 쓰는 이유다. Accuracy는 미분이 안 돼 학습에 직접 쓰지 못하므로, 학습은 교차 엔트로피로 하고 평가는 Accuracy·F1·ROC-AUC 등으로 한다. \[lecture\_017\]

**흐름**

- ① 모델이 정답 범주의 확률 p 출력
- ② −log(정답 확률)로 벌점 계산
- ③ 전체 데이터 평균 = 손실
- ④ 역전파·경사하강으로 손실 최소화

**헷갈리는 점**

- **흔한 오해** 학습 손실(교차 엔트로피)과 평가 지표(Accuracy)를 같은 것으로 봄
- **차이** 교차 엔트로피 = 확률의 질까지 보는 학습용 손실 / Accuracy = 맞힌 비율만 보는 평가용 지표
- **기억법** 교차 엔트로피는 '얼마나 자신 있게 맞혔나'까지 채점

**예시**

- 정답 1, 예측 0.9 → 손실 0.105 / 예측 0.5 → 0.693 / 예측 0.1 → 2.303
- 다중 분류는 Softmax 출력 + 범주형 교차 엔트로피

**카톡으로 이해하기**

> **💬 A** 교차 엔트로피는 분류 모델 채점표야
>
> **🙋 B** 맞으면 0점, 틀리면 1점 아냐?
>
> **💬 A** 더 세밀해. 정답에 준 확률이 낮을수록 벌점이 확 커져
>
> **🙋 B** 예를 들면?
>
> **💬 A** 정답에 0.9 주면 0.1점, 0.1 주면 2.3점
>
> **🙋 B** Accuracy 쓰면 안 돼?
>
> **💬 A** Accuracy는 미분이 안 돼서 학습엔 못 써. 학습은 교차 엔트로피, 평가는 Accuracy·F1
>
> **🙋 B** 우도랑도 관련 있다며?
>
> **💬 A** 교차 엔트로피 줄이기 = 우도 키우기. 같은 문제야

### 교차검증 (Cross-Validation)

`ML` · k-fold Cross-Validation · 추가 2026-10-25

> **한 번의 운이 아니라 k번 평균으로 모델을 비교**

**정의** 데이터를 k개 조각으로 나눠, 조각 하나씩 돌아가며 검증용으로 쓰고 나머지로 학습해 성능의 평균과 흔들림을 보는 평가 방법

**자세히**

k-fold 교차검증: 데이터를 k개(보통 5·10)로 나눠 k번 학습·검증하고 평균과 표준편차를 본다. 데이터를 한 번만 나누면 운에 따라 성능이 달라지기 때문이다. 모델 비교(SVM vs 랜덤포레스트)나 하이퍼파라미터 튜닝은 같은 폴드에서 해야 공정하다. 불균형 데이터는 층화(stratified) k-fold, 시계열은 시간 순서를 지키는 분할을 쓴다. 테스트 데이터는 교차검증과 별도로 맨 마지막에 한 번만 쓴다. \[lecture\_017\]

**흐름**

- ① 데이터를 k개 폴드로 분할(필요하면 층화)
- ② 폴드 하나로 검증, 나머지로 학습 → k번 반복
- ③ 성능 평균·표준편차 계산
- ④ 같은 폴드 기준으로 모델·설정 비교 → 테스트로 최종 확인

**헷갈리는 점**

- **흔한 오해** 검증(validation) 데이터와 테스트(test) 데이터를 같은 것으로 봄
- **차이** 검증 = 모델·설정을 고를 때 반복 사용 / 테스트 = 다 고른 뒤 마지막에 한 번만 보는 실력 확인
- **기억법** 검증은 모의고사(여러 번), 테스트는 수능(한 번)

**예시**

- 5-fold: 1~4조각으로 학습 → 5조각으로 검증, 이걸 5번 돌려 평균 정확도 0.91 ± 0.02
- SVM과 RF의 ROC-AUC를 같은 5개 폴드에서 비교

**카톡으로 이해하기**

> **💬 A** 모델 성능을 한 번만 재면 위험한 거 알아?
>
> **🙋 B** 왜?
>
> **💬 A** 데이터를 어떻게 나눴냐에 따라 운이 섞이거든
>
> **🙋 B** 그럼 어떻게 해?
>
> **💬 A** 5조각으로 나눠서 돌아가며 한 조각씩 시험 봐. 5번 평균 내는 게 교차검증이야
>
> **🙋 B** 테스트 데이터랑은 달라?
>
> **💬 A** 교차검증은 모의고사, 테스트는 수능. 수능은 마지막에 한 번만

### 규제 (Regularization)

`ML` · Regularization · 추가 2026-10-25

> **모델에 거는 '과속 방지턱' — 한국어 '정규화'(Normalization)와 다르다**

**정의** 모델이 학습 데이터에 과하게 맞춰지지 않도록 복잡도에 벌점이나 제약을 거는 방법 — 과적합을 줄이는 도구

**자세히**

대표 방법: L2(가중치 제곱합 벌점, Ridge), L1(절댓값 벌점, Lasso — 일부 계수를 0으로 만들어 변수 선택 효과), Dropout(학습 중 뉴런 일부를 무작위로 끔), Early Stopping(검증 손실이 다시 오르면 학습 중단), 데이터 증강. SVM의 C는 규제 세기와 반대로 움직인다(C가 작을수록 규제가 강해 마진이 넓다). Batch Normalization은 원래 층 입력의 분포를 맞춰 학습을 안정시키는 정규화(Normalization)이고 규제 효과는 부수적이다. (lecture\_017 검토: 덱 용어집 '정규화' 항목에 두 개념이 섞여 있음) \[lecture\_017\]

**흐름**

- ① 학습·검증 성능 차이로 과적합 확인
- ② 규제 방법 선택(L1·L2·Dropout·Early Stopping)
- ③ 규제 세기를 하이퍼파라미터로 튜닝
- ④ 교차검증으로 일반화 개선 확인

**헷갈리는 점**

- **흔한 오해** Regularization(규제)과 Normalization(정규화)이 한국어로 둘 다 '정규화'라 불려 섞임
- **차이** 규제 = 과적합 억제(벌점·제약) / 정규화(Normalization) = 입력·층 값의 범위·분포 맞추기(Min-Max, 표준화, Batch Normalization)
- **기억법** 규제는 브레이크, 정규화는 단위 맞추기

**예시**

- Ridge 회귀: 계수가 커지면 벌점 → 계수가 작고 부드러운 모델
- Dropout 0.5: 학습 때마다 뉴런 절반을 꺼서 특정 뉴런 의존을 줄임
- Early Stopping: 검증 손실이 5에포크 연속 안 줄면 중단

**카톡으로 이해하기**

> **💬 A** 규제(Regularization) 알아?
>
> **🙋 B** 정규화랑 같은 거 아냐?
>
> **💬 A** 한국어로 둘 다 정규화라고 부르는데 사실 달라
>
> **🙋 B** 뭐가 달라?
>
> **💬 A** 규제는 모델이 너무 외우지 않게 벌점 주는 거. Dropout, Early Stopping 같은 거  
> Normalization은 숫자 범위를 맞추는 거야
>
> **🙋 B** Batch Normalization은 어느 쪽이야?
>
> **💬 A** 원래는 Normalization. 학습을 안정시키려고 만든 거고 규제 효과는 덤이야

### 딥러닝 (Deep Learning)

`ML` · Deep Learning · 추가 2026-10-09

> **여러 층의 인공신경망을 쌓아 복잡한 패턴을 학습하는 머신러닝 방식**

**자세히**

딥러닝은 인공신경망을 여러 층(deep)으로 쌓아 이미지·음성·텍스트 등 복잡한 데이터에서 패턴을 스스로 찾아내는 방법이다. LLM(GPT, Claude 등)의 핵심 기술이 딥러닝이다.

**흐름**

- ① 대용량 데이터 준비
- ② 깊은 신경망(은닉층 多) 설계
- ③ 순전파 → 예측
- ④ 손실 계산 → 역전파
- ⑤ 에포크 반복 → 수렴

**헷갈리는 점**

- **흔한 오해** 딥러닝과 머신러닝을 별개로 오해
- **차이** 딥러닝 ⊂ 머신러닝 — 딥러닝은 신경망을 깊게 쌓은 머신러닝의 일종
- **기억법** 머신러닝 = 큰 원 / 딥러닝 = 그 안의 작은 원

**예시**

- 이미지 인식 — 수백만 장 사진으로 고양이·개 구분 학습
- 음성 인식 — 수억 개 음성 데이터로 말을 텍스트로 변환
- ChatGPT — 수조 개 텍스트로 딥러닝 학습한 결과
- 머신러닝 ⊃ 딥러닝 ⊃ Transformer ⊃ LLM (포함 관계)

**카톡으로 이해하기**

> **💬 A** 딥러닝이 머신러닝이랑 다른 거야?
>
> **🙋 B** 그냥 더 발전한 거 아니야?
>
> **💬 A** 딥러닝이 머신러닝의 하위 개념이야. 머신러닝 안에 딥러닝이 있어  
> 딥러닝은 인공신경망을 깊게 쌓아서 학습하는 방식이야
>
> **🙋 B** 그냥 머신러닝 쓰면 안 돼?
>
> **💬 A** 이미지·텍스트·음성 같은 복잡한 데이터는 딥러닝이 훨씬 잘 해  
> 전통 머신러닝은 사람이 특징(feature) 직접 설계해야 했는데  
> 딥러닝은 특징 추출까지 스스로 학습해
>
> **🙋 B** 아 그래서 요즘 AI가 이미지 인식도 잘 하는 거구나
>
> **💬 A** 맞아! 딥러닝 = 머신러닝 + 깊은 신경망  
> AI > 머신러닝 > 딥러닝 순서로 포함 관계야

### 로지스틱 회귀 (Logistic Regression)

`ML` · Logistic Regression · 추가 2026-10-25

> **로그오즈는 직선, 확률은 S자 곡선 — 이름은 회귀지만 분류에 쓰는 확률모형**

**정의** 입력의 가중합(로그오즈)을 시그모이드로 0~1 확률로 바꿔 이진 분류하는 통계 모형

**자세히**

Y|X ~ Bernoulli(p(X)), log(p/(1−p)) = β₀+β₁x₁+β₂x₂. 계수는 최대우도추정(MLE)으로 구하며, 이것은 교차 엔트로피를 최소화하는 것과 같다. 결정 경계(p=0.5)는 선형결합이 0이 되는 직선(초평면)이다. 계수의 부호·크기와 오즈비(e^β: x가 1 늘 때 오즈가 몇 배가 되는지)로 해석할 수 있어 설명이 필요한 문제(대출 심사 등)에 많이 쓴다. 은닉층이 0개이고 시그모이드 출력을 쓰는 신경망과 같은 모형이다. \[lecture\_017\]

**흐름**

- ① 입력 변수의 가중합 z = β₀+β₁x₁+… 계산
- ② 시그모이드로 확률 p = 1/(1+e^−z) 변환
- ③ 우도 최대화(=교차 엔트로피 최소화)로 β 추정
- ④ 임계값(보통 0.5)으로 분류 → 계수·오즈비로 해석

**헷갈리는 점**

- **흔한 오해** 이름에 '회귀'가 있어서 연속값을 예측하는 모델로 오해
- **차이** 확률(0~1)을 회귀식으로 모델링한 뒤 임계값으로 범주를 정하는 분류 모형. 연속값 예측은 선형 회귀
- **기억법** 속은 회귀(로그오즈 직선), 겉은 분류(확률 → 예/아니오)

**예시**

- 대출 연체 여부: 소득·부채비율로 연체 확률을 계산하고 0.5(또는 정한 임계값)를 넘으면 '위험'
- 오즈비 해석: 부채비율 계수 β=0.7 → 부채비율이 1 늘면 연체 오즈가 e^0.7≈2배
- lecture\_017 데모: 데이터 A(정규형 두 집단)에 경사하강법으로 적합한 직선 경계

**카톡으로 이해하기**

> **💬 A** 로지스틱 회귀 알아?
>
> **🙋 B** 회귀면 숫자 예측하는 거 아냐?
>
> **💬 A** 이름만 회귀야. 실제론 '연체할까 말까' 같은 분류에 써
>
> **🙋 B** 어떻게 분류해?
>
> **💬 A** 변수들 가중합을 시그모이드에 넣어서 0~1 확률로 바꿔. 0.5 넘으면 '예'
>
> **🙋 B** 딥러닝보다 좋은 점은?
>
> **💬 A** 계수로 설명이 돼. '부채비율 1 늘면 연체 오즈가 2배' 이렇게
>
> **🙋 B** 신경망이랑은 아예 달라?
>
> **💬 A** 은닉층 없는 신경망이 바로 로지스틱 회귀야. 같은 식이야

### 분류 (Classification)

`ML` · Classification · 추가 2026-10-09 · 보강 2026-10-25

> **입력 데이터가 어떤 범주(카테고리)에 속하는지 예측하는 머신러닝 과제**

**자세히**

분류는 주어진 데이터를 미리 정해진 카테고리 중 하나로 나누는 작업이다. 스팸/정상, 고양이/개, 긍정/부정처럼 '어느 쪽인가'를 판단한다. 로지스틱 회귀, SVM, Random Forest, 딥러닝 등이 분류에 사용된다.  
\[lecture\_017 보강\] 같은 분류 목적을 세 렌즈로 본다: 전통 통계학(로지스틱 회귀·LDA — 확률 가정·우도·해석), 머신러닝(SVM·랜덤포레스트 — 마진·불순도·유연한 경계), 인공신경망(퍼셉트론·MLP — 손실 최소화·비선형 표현). 분류는 y=f(x)에서 y가 범주형인 경우이고, y가 연속형이면 회귀 문제다.

**흐름**

- ① 입력 데이터
- ② 모델이 각 클래스 확률 계산(Softmax)
- ③ Threshold 기준으로 클래스 결정
- ④ 분류 결과 반환

**헷갈리는 점**

- **흔한 오해** 분류(Classification)와 회귀(Regression) 혼동
- **차이** 분류 = 카테고리 예측(스팸/정상) / 회귀 = 연속값 예측(집값·온도)
- **기억법** 분류 = 어느 바구니? / 회귀 = 얼마?

**예시**

- 이메일 → 스팸 or 정상 (이진 분류)
- 사진 → 고양이·개·새 중 하나 (다중 분류)
- 리뷰 텍스트 → 긍정·부정·중립 (감성 분류)
- AI가 수능 문제 → 국어·수학·영어 중 어느 과목인지 분류

**카톡으로 이해하기**

> **💬 A** 분류가 머신러닝에서 뭔 뜻이야?
>
> **🙋 B** 그냥 카테고리 나누는 거 아니야?
>
> **💬 A** 맞아! 입력 데이터가 어떤 클래스에 속하는지 예측하는 거야  
> 스팸 메일인가 아닌가, 강아지인가 고양이인가 이런 거
>
> **🙋 B** 그럼 숫자 예측하는 거(예: 집값)랑은 다른 거야?
>
> **💬 A** 달라! 집값 예측은 회귀(Regression), 카테고리 분류는 분류(Classification)이야  
> 출력이 연속적인 숫자면 회귀, 이산적인 클래스면 분류
>
> **🙋 B** 아 이진 분류는 두 가지 중 하나고, 다중 분류는 여러 가지 중 하나구나
>
> **💬 A** 딱 맞아! 이진=스팸/정상, 다중=고양이/강아지/새 이런 식이야  
> 머신러닝 문제 유형 중 가장 많이 쓰여

### 선형판별분석 (LDA)

`ML` · Linear Discriminant Analysis · 추가 2026-10-25

> **집단별 분포를 가정하고 비교해 직선 경계를 긋는 분류법 — '공분산이 같다'는 가정이 핵심**

**정의** 각 집단의 평균과 공통 공분산을 이용해, 집단 간 퍼짐은 크고 집단 내부 퍼짐은 작게 보이는 방향으로 선형 경계를 정하는 통계적 분류 방법

**자세히**

클래스마다 정규분포를 따르고 공분산은 같다고 가정하면 경계가 직선이 된다. 클래스마다 공분산이 다르다고 두면 QDA(이차판별분석)가 되어 곡선 경계가 나온다. 로지스틱 회귀는 P(Y|X)만 모델링하지만, LDA는 X가 각 집단에서 어떻게 분포하는지까지 모델링한다. 그래서 가정이 맞으면 적은 데이터로도 효율적이지만, 가정이 틀리면(이상치·비정규) 흔들린다. 차원 축소에도 쓴다. \[lecture\_017\]

**흐름**

- ① 집단별 평균 계산
- ② 집단 내부 공분산(공통) 계산
- ③ 집단 간 퍼짐 ÷ 집단 내부 퍼짐이 가장 커지는 방향 찾기
- ④ 그 방향 위의 선형 경계로 새 데이터 판별

**헷갈리는 점**

- **흔한 오해** LDA라는 약자가 토픽 모델링의 LDA(Latent Dirichlet Allocation)와 같음
- **차이** 분류의 LDA = 선형판별분석(지도학습) / 토픽의 LDA = 문서 주제 찾기(비지도학습). 로지스틱 회귀와는 'X의 분포를 가정하느냐'가 다름
- **기억법** 판별 LDA는 '집단 비교', 토픽 LDA는 '주제 뽑기'

**예시**

- 두 품종 꽃의 꽃잎 길이·폭으로 품종 판별 (피셔의 붓꽃 데이터가 원조)
- lecture\_017 데모: 데이터 A에서 평균 2개 + 공통 공분산을 실제로 계산해 그린 직선 경계
- 공분산을 집단마다 따로 두면 QDA → 곡선 경계

**카톡으로 이해하기**

> **💬 A** LDA라고 들어봤어?
>
> **🙋 B** 그거 문서 주제 뽑는 거 아냐?
>
> **💬 A** 그건 이름만 같은 다른 LDA야. 여기선 선형판별분석
>
> **🙋 B** 뭘 판별해?
>
> **💬 A** 두 집단 평균이랑 퍼진 정도를 비교해서 그 사이에 직선을 그어
>
> **🙋 B** 로지스틱 회귀랑 뭐가 달라?
>
> **💬 A** LDA는 '각 집단이 정규분포고 퍼짐이 같다'고 가정해. 맞으면 효율적이고, 틀리면 흔들려
>
> **🙋 B** 퍼짐이 다르면?
>
> **💬 A** 그럼 QDA. 경계가 곡선이 돼

### 어텐션 (Attention)

`ML` · Attention Mechanism · 추가 2026-10-09

> **문장에서 지금 이 단어와 관련 있는 다른 단어에 집중(가중치 부여)하는 메커니즘**

**자세히**

어텐션은 문장 안의 각 단어가 다른 단어들과 얼마나 관련 있는지 점수를 매기는 방식이다. 예를 들어 '그것'이라는 단어가 앞 문장의 어떤 명사를 가리키는지 파악할 때 어텐션이 작동한다. Transformer의 핵심 원리이며, Query·Key·Value(Q·K·V) 구조로 계산된다.

**흐름**

- ① 각 토큰을 Q(쿼리)·K(키)·V(값)으로 변환
- ② Q와 K의 내적으로 어텐션 점수 계산
- ③ Softmax로 확률 변환
- ④ V와 가중합 → 맥락 반영된 벡터
- ⑤ 다음 레이어로 전달

**헷갈리는 점**

- **흔한 오해** 어텐션을 단순 '집중'으로만 이해
- **차이** 어텐션 = 수학적으로 각 단어가 다른 단어와의 관련도를 점수로 계산하는 메커니즘
- **기억법** 검색엔진 비유: Q=검색어 / K=페이지 제목 / V=페이지 내용

**예시**

- '은행에 갔다' — '은행'이 금융기관인지 강가인지: 앞뒤 단어에 어텐션 부여해 판단
- '그는 컵을 떨어뜨렸고 그것이 깨졌다' — '그것'=컵 : 어텐션이 컵에 높은 점수
- Q(질문) · K(키) · V(값) — 검색엔진 비유: 쿼리로 검색해 관련 내용 가져오기
- Multi-Head Attention = 여러 관점에서 동시에 어텐션 계산

**카톡으로 이해하기**

> **💬 A** 어텐션이 Transformer에서 뭔 역할이야?
>
> **🙋 B** 주의를 기울인다는 거?
>
> **💬 A** 맞아! 입력 문장에서 어떤 단어가 다른 단어와 얼마나 관련 있는지 가중치로 계산하는 메커니즘이야
>
> **🙋 B** 예시 들어줘
>
> **💬 A** '나는 배가 고프다'에서 '고프다'를 이해할 때 '배'가 중요하잖아  
> 어텐션이 '고프다' ↔ '배' 관계에 높은 가중치 줘서 더 집중해서 보는 거야
>
> **🙋 B** 아 문맥을 이해하는 방식이구나
>
> **💬 A** 맞아! 어텐션 덕분에 긴 문장에서도 멀리 있는 단어들 사이 관계를 잡을 수 있어  
> Transformer의 핵심이야

### 에포크 (Epoch)

`ML` · Epoch · 추가 2026-10-09

> **전체 학습 데이터를 한 번 모두 학습한 횟수 단위**

**자세히**

에포크는 모델이 전체 훈련 데이터를 처음부터 끝까지 한 번 다 본 것을 1 에포크라고 한다. 보통 수십~수백 에포크를 반복하며 모델이 점점 정확해진다. 에포크가 너무 많으면 과적합(overfitting)이 발생할 수 있다.

**흐름**

- ① 전체 학습 데이터 준비
- ② 배치 단위로 나눔
- ③ 모든 배치 학습 완료 = 1 에포크
- ④ 다음 에포크 시작(데이터 섞기)
- ⑤ N 에포크 완료 → 학습 종료

**헷갈리는 점**

- **흔한 오해** 에포크와 배치(batch) 혼동
- **차이** 배치 = 한 번에 학습하는 데이터 묶음 / 에포크 = 전체 데이터를 한 번 다 본 것
- **기억법** 에포크 = 책 한 권 다 읽기 / 배치 = 책 한 챕터 읽기

**예시**

- 10만 개 데이터를 1번 다 학습 = 1 에포크
- 100 에포크 학습 = 같은 데이터를 100번 반복해서 학습
- 에포크 증가 → 정확도 향상 → 일정 이상은 과적합 발생
- 라이프루프의 '반복 실행'과 같은 개념 — 반복할수록 개선됨

**카톡으로 이해하기**

> **💬 A** 에포크가 뭔지 알아? 딥러닝 학습할 때 나오는 거
>
> **🙋 B** 처음 들어봐
>
> **💬 A** 전체 학습 데이터를 한 번 다 돌리는 게 1 에포크야  
> 학습 데이터가 1000개면 1000개 다 학습하면 1 에포크 완료
>
> **🙋 B** 여러 번 반복하는 거야?
>
> **💬 A** 응! 보통 10~100 에포크씩 학습해. 반복할수록 모델이 점점 정확해져  
> 근데 너무 많이 하면 학습 데이터에만 맞는 과적합이 생겨
>
> **🙋 B** 아 적당히 해야 하는 거구나
>
> **💬 A** 맞아! 에포크 = 학습 데이터를 몇 바퀴 돌렸는지  
> 1에포크=전체 데이터 1회 학습, 10에포크=10회 반복이야

### 역전파 (Backpropagation)

`ML` · Backpropagation · 추가 2026-10-25

> **오차를 뒤에서 앞으로 나눠 주는 계산법 — 가중치를 실제로 고치는 건 경사하강법**

**정의** 출력의 오차가 각 가중치에 얼마나 영향을 줬는지(기울기)를 연쇄법칙으로 출력층에서 입력층 쪽으로 거꾸로 계산하는 방법

**자세히**

순전파로 예측을 내고 손실(예: 교차 엔트로피)을 계산한 뒤, 미분의 연쇄법칙으로 각 층 가중치의 기울기를 뒤에서부터 차례로 구한다. 이렇게 구한 기울기로 경사하강법이 가중치를 업데이트한다. 은닉층이 있는 신경망 학습을 현실적으로 만든 핵심 기법이다. \[lecture\_017\]

**흐름**

- ① 순전파: 입력 → 은닉층 → 출력으로 예측
- ② 손실 계산: 예측과 정답의 차이
- ③ 역전파: 출력층부터 거꾸로 각 가중치의 기울기 계산(연쇄법칙)
- ④ 경사하강법으로 가중치 업데이트 → 반복

**헷갈리는 점**

- **흔한 오해** 역전파 = 학습 그 자체라고 생각
- **차이** 역전파 = 기울기 '계산' / 경사하강법(옵티마이저) = 그 기울기로 가중치 '이동'
- **기억법** 역전파는 내비가 방향 계산, 경사하강은 실제로 운전

**예시**

- 시험 오답 원인을 '마지막 계산 실수 → 공식 적용 → 개념 이해' 순으로 거꾸로 추적하는 것과 비슷
- lecture\_017 데모: ReLU 은닉층 + 시그모이드 출력 신경망이 두 반달 경계를 역전파로 학습(학습 정확도 96.3%)

**카톡으로 이해하기**

> **💬 A** 역전파가 뭔지 알아?
>
> **🙋 B** 뭔가 거꾸로 전달하는 거?
>
> **💬 A** 맞아. 틀린 정도(오차)를 출력층에서 앞쪽 층으로 거꾸로 나눠 줘
>
> **🙋 B** 왜 거꾸로 해?
>
> **💬 A** 각 가중치가 오차에 얼마나 책임 있는지 계산하려고. 미분 연쇄법칙을 써
>
> **🙋 B** 그게 학습이야?
>
> **💬 A** 반만. 역전파는 방향 계산이고, 실제로 가중치를 옮기는 건 경사하강법이야

### 우도·최대우도추정 (Likelihood·MLE)

`ML` · Likelihood · Maximum Likelihood Estimation · 추가 2026-10-25

> **데이터를 가장 그럴듯하게 설명하는 파라미터 고르기**

**정의** 우도는 '지금 파라미터라면 관측한 데이터가 나올 법한 정도'이고, MLE는 그 우도를 가장 크게 만드는 파라미터를 고르는 추정 방법

**자세히**

확률은 파라미터를 고정하고 데이터가 나올 가능성을 보는 것이고, 우도 L(θ)=P(데이터|θ)는 데이터를 고정하고 파라미터 θ를 바꿔 가며 보는 것이다. 곱셈이 많아 보통 로그우도를 최대화한다. 로지스틱 회귀에서 로그우도 최대화는 교차 엔트로피 최소화와 같은 문제다. 통계학은 우도를 바탕으로 우도비검정·AIC/BIC 같은 모형 비교도 한다. \[lecture\_017\]

**흐름**

- ① 데이터 분포 가정(예: 베르누이)
- ② 파라미터 θ에 대한 우도(로그우도) 식 세우기
- ③ 우도가 최대가 되는 θ 찾기(미분·경사법)
- ④ 추정값으로 예측·검정·해석

**헷갈리는 점**

- **흔한 오해** 우도 = 그 파라미터가 맞을 확률이라고 오해
- **차이** 우도는 파라미터의 확률이 아님. '이 파라미터면 이 데이터가 나올 법한 정도'. 파라미터 자체의 확률은 베이즈 사후확률
- **기억법** 확률은 '공정한 주사위로 6이 나올까?', 우도는 '6이 이렇게 많이 나왔으니 어떤 주사위가 그럴듯할까?'

**예시**

- 동전 10번 중 앞면 7번 → 앞면 확률 0.7일 때 우도가 가장 큼 → MLE = 0.7
- 로지스틱 회귀 계수 추정 = 로그우도 최대화 = 교차 엔트로피 최소화

**카톡으로 이해하기**

> **💬 A** 우도가 뭔지 헷갈리지?
>
> **🙋 B** 확률이랑 같은 거 아냐?
>
> **💬 A** 방향이 반대야. 확률은 동전이 정해져 있을 때 결과를 봐
>
> **🙋 B** 우도는?
>
> **💬 A** 결과가 정해져 있을 때 '어떤 동전이 그럴듯한가'를 봐
>
> **🙋 B** 그럼 MLE는?
>
> **💬 A** 그럴듯함이 가장 큰 값을 고르는 거야. 10번 중 7번 앞면이면 0.7
>
> **🙋 B** 머신러닝이랑도 관련 있어?
>
> **💬 A** 로지스틱 회귀에서 우도 최대화가 교차 엔트로피 최소화랑 똑같아

### 은닉층 (Hidden Layer)

`ML` · Hidden Layer · 추가 2026-10-09 · 보강 2026-10-25

> **입력층과 출력층 사이에서 특징을 추출·변환하는 중간 레이어**

**자세히**

은닉층은 인공신경망에서 입력(X)과 출력(Y) 사이에 있는 중간 계층이다. 눈에 보이지 않아서 '은닉(hidden)'이라 불린다. 은닉층이 많을수록 복잡한 패턴을 학습할 수 있으며, 딥러닝은 이 은닉층이 깊게 쌓인 것이다.  
\[lecture\_017 보강\] 단일 퍼셉트론은 직선 하나로만 나눠 XOR·두 반달 데이터를 못 푼다 — 은닉층과 비선형 활성화가 필요해진 역사적 동기. 은닉층 0개 + 시그모이드 출력 = 로지스틱 회귀.

**흐름**

- ① 입력층에서 데이터 수신
- ② 은닉층1: 단순 패턴(선·색) 추출
- ③ 은닉층2: 복합 패턴(눈·코·귀) 추출
- ④ 은닉층N: 추상적 특징(얼굴·표정) 추출
- ⑤ 출력층으로 전달

**헷갈리는 점**

- **흔한 오해** 은닉층이 많을수록 무조건 좋다고 오해
- **차이** 은닉층이 많으면 복잡한 패턴 학습 가능하지만 과적합·학습 난이도 증가
- **기억법** 층이 많을수록 = 더 깊은 요리사 실력, 하지만 배우기도 더 어려움

**예시**

- 입력층(픽셀) → 은닉층1(선·모서리) → 은닉층2(눈·코·귀) → 출력층(얼굴 인식)
- 은닉층 1개 = 얕은 신경망 / 은닉층 100개 = 딥러닝
- GPT 같은 대형 모델은 수백 개의 은닉층(Transformer 블록)을 가짐
- 은닉층이 많을수록 더 추상적이고 복잡한 특징을 학습

**카톡으로 이해하기**

> **💬 A** 은닉층이 딥러닝에서 뭔지 알아?
>
> **🙋 B** 숨겨져 있는 층?
>
> **💬 A** 맞아! 인공신경망에서 입력층과 출력층 사이에 있는 층들이야  
> 눈에 직접 보이지 않는다고 '은닉'이라고 해
>
> **🙋 B** 왜 필요한 거야?
>
> **💬 A** 은닉층이 없으면 단순한 선형 계산만 할 수 있어  
> 은닉층이 여러 개 있으면 복잡한 패턴도 학습할 수 있어
>
> **🙋 B** 그럼 많을수록 좋아?
>
> **💬 A** 무조건은 아니야. 너무 많으면 학습이 불안정해지고 느려져  
> 딥러닝이 깊은(Deep) 건 이 은닉층이 여러 층 쌓인 거야  
> 은닉층 = 뇌의 중간 처리 단계라고 생각해

### 인공신경망 (Artificial Neural Network)

`ML` · Artificial Neural Network · 추가 2026-10-09 · 보강 2026-10-25

> **인간 뇌의 뉴런 구조를 모방해 만든 AI 학습 구조**

**자세히**

인공신경망은 입력층·은닉층·출력층으로 구성된 노드(뉴런)들의 연결망이다. 각 연결에는 가중치(weight)가 있고, 학습을 통해 이 가중치가 조정되면서 모델이 정확해진다. 딥러닝은 이 신경망을 깊게(여러 층으로) 쌓은 것이다.  
\[lecture\_017 보강\] 시그모이드 출력 + 교차 엔트로피로 학습하는 이진 분류 신경망은 Y|X~Bernoulli 확률모형이며, 은닉층이 0개면 로지스틱 회귀와 같다. 은닉층 + 비선형 활성화가 곡선 결정 경계를 만든다. 보편 근사 정리는 표현력에 대한 정리일 뿐 일반화를 보장하지 않는다.

**흐름**

- ① 입력 데이터 → 입력층 노드
- ② 가중치 곱 + 편향 → 은닉층 전달
- ③ 활성화 함수 적용
- ④ 다음 은닉층으로 전달 (반복)
- ⑤ 출력층 → 최종 예측값

**헷갈리는 점**

- **흔한 오해** 뇌와 똑같이 작동한다고 오해
- **차이** 인공신경망 = 뇌에서 영감받은 수학적 구조일 뿐, 실제 뇌와는 다름
- **기억법** 비행기가 새를 보고 만들었지만 새처럼 날개짓 안 하듯 — 영감만 받은 것

**예시**

- 입력층(사진 픽셀) → 은닉층(패턴 추출) → 출력층(고양이/개) 구조
- 뇌의 뉴런이 연결되어 신호를 전달하듯, 노드가 연결되어 숫자를 전달
- 가중치 = 연결의 중요도 — 학습으로 자동 조정됨
- GPT의 수천억 개 파라미터 = 인공신경망의 가중치 수

**카톡으로 이해하기**

> **💬 A** 인공신경망이 진짜 뇌 따라 만든 거야?
>
> **🙋 B** 뉴런 같은 거 있잖아?
>
> **💬 A** 뇌의 뉴런 구조에서 영감받은 거야. 완전히 똑같지는 않지만  
> 입력 받아서 가중치 곱해 계산하고 다음 노드로 전달하는 구조가 비슷해
>
> **🙋 B** 어떻게 학습하는 거야?
>
> **💬 A** 정답이랑 예측값 차이(손실)를 계산해서 역방향으로 가중치 조정해  
> 이걸 수만 번 반복하면서 점점 더 좋은 예측을 하게 돼
>
> **🙋 B** 아 그래서 학습 데이터가 많을수록 좋은 거구나
>
> **💬 A** 맞아! 입력층 → 은닉층(여러 개) → 출력층 구조가 인공신경망의 기본이야  
> 이 은닉층을 깊게 쌓은 게 딥러닝이야

### 전이학습 (Transfer Learning)

`ML` · Transfer Learning · 추가 2026-10-25

> **남이 키운 실력을 빌려 와 내 문제에 맞추기**

**정의** 큰 데이터로 미리 학습한 모델(사전학습 모델)의 지식을 가져와 새 과제에 맞게 조금 더 학습시키는 방법 — 파인튜닝을 포함한다

**자세히**

대규모 이미지 데이터로 학습한 이미지 모델이나 대형 언어모델(LLM)처럼 일반적인 특징을 이미 배운 모델을 출발점으로 삼는다. 새 데이터가 적어도 성능을 내기 쉽다. 방법: 앞쪽 층은 고정하고 마지막 층만 새로 학습(특징 추출), 또는 전체를 작은 학습률로 다시 학습(파인튜닝). LLM에서는 LoRA처럼 일부 파라미터만 학습하는 방법도 쓴다. \[lecture\_017\]

**흐름**

- ① 사전학습 모델 고르기
- ② 새 과제에 맞게 출력층 교체
- ③ 일부 층 고정 또는 전체를 작은 학습률로 학습
- ④ 검증 데이터로 성능 확인

**헷갈리는 점**

- **흔한 오해** 전이학습과 파인튜닝을 완전히 다른 것으로 봄
- **차이** 전이학습 = 사전학습 지식을 옮겨 쓰는 큰 개념 / 파인튜닝 = 그 안의 한 방법(가중치를 추가 학습)
- **기억법** 전이학습은 '경력자 채용', 파인튜닝은 '우리 회사 OJT'

**예시**

- 사전학습 이미지 모델 + 공장 불량품 사진 500장 → 불량 판별 모델
- 범용 LLM을 학교 행정 문서로 파인튜닝

>

### 지니 불순도 (Gini Impurity)

`ML` · Gini Impurity · 추가 2026-10-25

> **섞임 정도 점수: 0 = 깔끔, 이진 분류 최대 0.5 = 반반**

**정의** 트리의 한 노드에 여러 범주가 얼마나 섞여 있는지 재는 값 — 0이면 한 범주만 있는 순수한 상태

**자세히**

G = 1 − Σ pₖ² (이진이면 2p(1−p)). 결정 트리는 분할 후 두 자식 노드의 지니 불순도 가중평균이 가장 작아지는 기준으로 데이터를 나눈다. 랜덤포레스트의 변수 중요도(MDI)는 각 변수가 줄인 지니 불순도를 모든 트리에서 합한 비율이다. 엔트로피(정보 이득)도 같은 역할을 하며 결과는 대체로 비슷하다. \[lecture\_017\]

**흐름**

- ① 후보 분할 기준(변수·임계값) 만들기
- ② 분할 후 양쪽 노드의 지니 불순도 계산
- ③ 가중평균이 가장 작은 분할 선택
- ④ 더 나눌 필요가 없을 때까지 반복

**헷갈리는 점**

- **흔한 오해** 경제학의 지니 계수(소득 불평등)와 같은 것으로 착각
- **차이** 지니 불순도 = 노드 안 범주 섞임 / 지니 계수 = 소득 분배 불평등. 같은 학자(지니)의 이름을 땄을 뿐 계산·의미가 다름
- **기억법** 불순도는 '바구니 속 과일이 몇 종류 섞였나'

**예시**

- 노드에 스팸 5·정상 5 → 1−(0.5²+0.5²) = 0.5 (가장 섞임)
- 스팸 9·정상 1 → 1−(0.81+0.01) = 0.18
- 스팸만 10 → 0 (순수)

**카톡으로 이해하기**

> **💬 A** 결정 트리가 어디서 자를지 어떻게 정하는지 알아?
>
> **🙋 B** 아무 데나 자르는 거 아냐?
>
> **💬 A** 지니 불순도가 제일 많이 줄어드는 곳을 골라
>
> **🙋 B** 지니 불순도가 뭔데?
>
> **💬 A** 한 바구니에 범주가 얼마나 섞였나 점수야. 반반이면 0.5, 한 종류면 0
>
> **🙋 B** 소득 불평등 지니 계수랑 같은 거야?
>
> **💬 A** 이름만 같아. 계산도 의미도 달라

- 학생 성적(X) + 합격여부(Y) → 합격 예측 모델

### 퍼셉트론 (Perceptron)

`ML` · Perceptron · 추가 2026-10-25

> **틀리면 고치는 직선 하나 — 신경망의 출발점이자 XOR을 못 푸는 한계의 상징**

**정의** 입력의 가중합에 계단 함수를 적용해 둘 중 하나로 분류하고, 틀린 샘플을 볼 때만 가중치를 고치는 가장 단순한 인공신경망

**자세히**

ŷ = step(w·x + b). 틀린 샘플에서만 w ← w + η(y−ŷ)x로 가중치를 옮긴다. 1958년 로젠블랫이 제안했다. 데이터가 직선으로 나뉘면 언젠가 모두 맞히는 경계를 찾지만(수렴 정리), XOR이나 두 반달처럼 직선 하나로 나뉘지 않으면 풀 수 없다. 1969년 민스키·패퍼트가 이 한계를 지적했고, 은닉층과 비선형 활성화를 쌓은 다층 퍼셉트론(MLP)과 역전파가 해법이 됐다. 단일 퍼셉트론은 역전파가 아니라 퍼셉트론 규칙으로 학습한다. \[lecture\_017\]

**흐름**

- ① 가중합 w·x+b 계산
- ② 계단 함수로 0/1(또는 −1/+1) 판정
- ③ 틀렸으면 정답 쪽으로 가중치 이동, 맞으면 그대로
- ④ 데이터를 여러 번 돌며 반복 → 직선 경계 확정

**헷갈리는 점**

- **흔한 오해** 퍼셉트론과 로지스틱 회귀가 같은 것으로 보임(둘 다 선형결합)
- **차이** 퍼셉트론 = 계단 함수로 맞다/틀리다만 보고 틀린 것만 수정 / 로지스틱 회귀 = 시그모이드로 확률을 내고 우도(교차 엔트로피)로 학습
- **기억법** 퍼셉트론은 OX 채점, 로지스틱은 확률 점수

**예시**

- AND·OR은 직선 하나로 나뉘어 퍼셉트론으로 풀림
- XOR(둘 중 하나만 참)은 직선 하나로 못 나눔 → 은닉층 필요
- lecture\_017 데모: 두 반달 데이터에 퍼셉트론 → 직선이라 반달을 감싸지 못함(학습 정확도 92.5%)

**카톡으로 이해하기**

> **💬 A** 퍼셉트론이 신경망의 할아버지야
>
> **🙋 B** 뭐 하는 건데?
>
> **💬 A** 입력에 가중치 곱해서 더하고, 기준 넘으면 1 아니면 0
>
> **🙋 B** 학습은 어떻게 해?
>
> **💬 A** 틀린 것만 보고 가중치를 정답 쪽으로 조금 옮겨
>
> **🙋 B** 그걸로 다 풀려?
>
> **💬 A** 직선 하나로 나뉘는 문제만. XOR은 못 풀어
>
> **🙋 B** 그럼 어떻게 해?
>
> **💬 A** 층을 쌓고 비선형 활성화를 넣어. 그게 다층 퍼셉트론, 딥러닝의 시작이야

**예시**

- 신경망: 학습률이 너무 크면 손실이 튀고, 너무 작으면 느림

### 혼동행렬·정밀도·재현율·F1

`ML` · Confusion Matrix · Precision · Recall · F1 · 추가 2026-10-25

> **Accuracy 하나에 숨는 실수를 네 칸으로 드러내는 평가 도구**

**정의** 분류 결과를 TP·FP·FN·TN 네 칸으로 정리한 표(혼동행렬)와, 거기서 계산하는 정밀도·재현율·F1 지표

**자세히**

정밀도 = TP/(TP+FP): '양성이라고 한 것 중 진짜 양성' 비율. 재현율 = TP/(TP+FN): '진짜 양성 중 찾아낸' 비율. F1 = 2·정밀도·재현율/(정밀도+재현율), 둘의 조화평균. 양성이 1%뿐이면 전부 음성이라고 해도 Accuracy 99%가 나오므로 불균형 데이터에선 혼동행렬과 정밀도·재현율을 함께 본다. 임계값을 높이면 정밀도↑·재현율↓, 낮추면 반대다. 무엇을 우선할지는 거짓양성·거짓음성의 비용으로 정한다. \[lecture\_017\]

**흐름**

- ① 예측과 정답으로 TP·FP·FN·TN 세기
- ② 정밀도·재현율·F1 계산
- ③ 거짓양성·거짓음성 비용 비교
- ④ 임계값 조정 또는 모델 변경

**헷갈리는 점**

- **흔한 오해** 정밀도와 재현율이 헷갈림
- **차이** 정밀도 = 내가 '양성'이라고 한 것의 정확도 / 재현율 = 실제 양성을 놓치지 않은 정도
- **기억법** 정밀도는 '헛방 줄이기', 재현율은 '빠짐없이 잡기'

**예시**

- 암 검진: 놓치면 치명적 → 재현율 우선
- 스팸 필터: 정상 메일을 스팸함에 넣으면 곤란 → 정밀도 우선
- 양성 10명 중 8명 찾고(TP 8, FN 2) 양성이라 한 것 중 4명은 오진(FP 4) → 재현율 0.8, 정밀도 0.67, F1 0.73

**카톡으로 이해하기**

> **💬 A** 정확도 99%면 좋은 모델일까?
>
> **🙋 B** 당연하지!
>
> **💬 A** 환자가 1%뿐이면 전부 '정상'이라 해도 99%야
>
> **🙋 B** 헐 그럼 뭘 봐?
>
> **💬 A** 혼동행렬. 맞힌 양성, 헛방, 놓친 양성, 맞힌 음성 네 칸으로 봐
>
> **🙋 B** 정밀도랑 재현율은?
>
> **💬 A** 정밀도는 '양성이라 한 것 중 진짜', 재현율은 '진짜 중 찾아낸 것'
>
> **🙋 B** 뭘 더 중요하게 봐?
>
> **💬 A** 틀렸을 때 비용으로 정해. 암 검진은 재현율, 스팸 필터는 정밀도. 둘 다 보려면 F1

### 활성화 함수 (Activation Function)

`ML` · Activation Function · 추가 2026-10-25

> **비선형 스위치 — 없으면 층을 아무리 쌓아도 직선 하나**

**정의** 신경망의 각 뉴런이 가중합을 다음 층으로 넘기기 전에 통과시키는 함수 — 비선형을 넣어 곡선 경계를 가능하게 한다

**자세히**

대표: 계단 함수(퍼셉트론, 0/1), 시그모이드 1/(1+e^−z)(0~1 확률, 이진 분류 출력층), ReLU max(0,z)(은닉층 기본값, 계산이 싸고 기울기 소실이 적음), Softmax(다중 분류 출력층, 확률 합 1), tanh. 선형 함수만 겹치면 결국 선형 함수 하나와 같아서, 은닉층이 있어도 비선형 활성화가 없으면 퍼셉트론과 같은 직선 경계밖에 못 만든다. \[lecture\_017\]

**흐름**

- ① 뉴런이 가중합 z 계산
- ② 활성화 함수 통과(은닉층은 ReLU 등)
- ③ 다음 층으로 전달
- ④ 출력층은 문제에 맞는 함수(이진=시그모이드, 다중=Softmax)

**헷갈리는 점**

- **흔한 오해** 층만 많이 쌓으면 복잡한 패턴을 배운다고 생각
- **차이** 비선형 활성화가 없으면 100층도 직선 1개와 같음. 층 수와 비선형이 함께 있어야 함
- **기억법** 직선 자를 백 개 이어도 직선, 꺾이는 관절(활성화)이 있어야 곡선

**예시**

- ReLU: 음수는 0, 양수는 그대로 → 여러 조각을 이어 꺾인 경계 생성
- 시그모이드: 점수 2.0 → 확률 0.88
- lecture\_017 데모: ReLU 뉴런 8개로 두 반달 사이 곡선 경계

**카톡으로 이해하기**

> **💬 A** 신경망에 활성화 함수가 왜 필요한지 알아?
>
> **🙋 B** 뉴런을 켜고 끄는 거?
>
> **💬 A** 비슷해. 핵심은 '꺾임'을 넣는 거야
>
> **🙋 B** 꺾임이 왜 중요해?
>
> **💬 A** 꺾임이 없으면 층을 100개 쌓아도 직선 하나랑 같아
>
> **🙋 B** 대표적인 건?
>
> **💬 A** 은닉층엔 ReLU, 이진 분류 출력엔 시그모이드, 여러 범주면 Softmax
